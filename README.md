# Customer Churn Prediction System

## Project Overview

This project is a Machine Learning based Customer Churn Prediction System. It predicts whether a customer is likely to leave a service based on customer behavior, subscription details, and service usage patterns.

## Objective

- Predict customer churn (Yes/No)
- Identify factors that influence customer churn
- Understand customer behavior
- Support customer retention strategies

## Dataset

The dataset contains 3000 synthetic customer records.

### Features

- CustomerID
- Age
- Gender
- SubscriptionType
- MonthlyCharges
- TenureMonths
- SupportTickets
- PaymentMethod
- SatisfactionScore
- UsageHoursPerWeek
- Churn

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## Machine Learning Models

- Logistic Regression
- Random Forest
- XGBoost

## Project Workflow

1. Data Generation
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Feature Importance Analysis
8. Customer Churn Prediction

## Outcome

The system helps identify customers who are likely to churn and provides insights that can support better customer retention decisions.
